# STAR AI Tracker — Landing Page

עמוד נחיתה בעברית (RTL) עבור **STAR AI / Star AI Tracker**.

## איך לפתוח

1. פתחו את הקובץ `index.html` בדפדפן (כפול־קליק, או גרירה לחלון הדפדפן).
2. אפשר גם מטרמינל:

```bash
# מתוך תיקייה זו
xdg-open index.html
# או
python3 -m http.server 8080
# ואז גלוש אל http://localhost:8080
```

העמוד עצמאי לחלוטין (HTML + CSS + JS מובנים). נטען גופן Heebo מ־Google Fonts אם יש אינטרנט; בלי אינטרנט יוצג גופן מערכת.
